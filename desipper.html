FAQ

Frequently asked.

What is de-essing?
De-essing is the process of taming harsh sibilant sounds — "s", "sh", "t", and "f" — in a vocal recording so they don't pierce through the mix. New to the concept? MusiCircuit's guide What is a De-Esser? How to Use One in 5 Simple Steps is a great walkthrough of the basics.
What is De-Sipper?
A transparent de-esser plugin that removes harsh sibilance from vocals. It uses split-band processing to target only the sibilant frequencies, leaving the rest of your vocal completely untouched.
What formats are supported?
De-Sipper is available as VST3, AU, AAX, and Standalone on macOS. On Windows, it ships as VST3 and Standalone.
How many computers can I use it on?
Up to 3 machines with one license. If you need to move an activation, just deactivate on the old machine and activate on the new one.
Is there a free trial?
Yes! Download the free demo here. It includes all DSP features with a periodic silence cycle (60 seconds on, 10 seconds muted) so you can fully evaluate De-Sipper before purchasing.
Does it work with Pro Tools?
Yes, De-Sipper is available as an AAX plugin on macOS, fully compatible with Pro Tools.
Does it add latency?
No. De-Sipper processes with zero latency — no lookahead buffer required. It works seamlessly for both tracking and mixing.
What's the refund policy?

How do I install it?
